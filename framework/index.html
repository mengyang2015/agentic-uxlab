Three phases

From delegation to better outcomes.

The stages help teams discuss where people need context, approval, evidence, or an opportunity to intervene. They are design guidance, not a rigid process every agent must follow.

01 / Before launch

Prepare

Make the agent's goal, authority, and readiness clear before it takes real action.

  • Define
  • Configure
  • Test
  • Launch

AI/Human Review + Recommendations checks readiness before launch. Gaps loop back to configuration and testing. Launch needs approval.

02 / Continuous

Run

Let the agent execute authorized work while people can observe progress and verify outcomes.

  • Execute
  • Monitor
  • Intervene when needed
  • Verify outcome

Intervention or approval happens when needed, not on every run. Evidence of completion matters more than a generic “Done.”

03 / Evidence-triggered

Improve

Turn feedback and failures into tested, reviewable improvements.

  • Evaluate
  • Adapt
  • Re-test
  • Release

Release is an approval gate and returns the improved agent to Run. Durable lessons inform future preparation.

Four human touchpoints.

  • Direct
  • Approve
  • Intervene
  • Verify
Design principle: Give agents autonomy. Keep humans accountable. The four touchpoints are human actions, not mandatory screens. Approval and verification should match the risk and consequence of the task.
